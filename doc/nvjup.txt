1. INTRODUCTION                                  *nvjup-introduction*

nvjup opens nbformat 4 *.ipynb files as editable notebook cells. Cell headers,
borders, execution counts, and saved outputs are rendered using extmarks and
virtual lines. Structural marker lines remain in the buffer for reliable undo
and saving, but are concealed in normal use.

==============================================================================
2. SETUP                                                   *nvjup-setup*

With a plugin manager, call:

>lua
  require("nvjup").setup({})
<

Options include:

>lua
  require("nvjup").setup({
    border_width = 88,
    render = {
      outputs = true,
      max_output_lines = 12,
      markdown = true,
      right_border = true,
    },
    treesitter = {
      enabled = true,
    },
    lsp = {
      auto_start = true,
      -- Python defaults to Pyright and Ruff when installed.
    },
    keymaps = {
      next_cell = "]c",
      previous_cell = "[c",
      -- Set any action to false to disable its mapping.
    },
  })
<

==============================================================================
3. NAVIGATION                                           *nvjup-navigation*

]c                      Next cell.
[c                      Previous cell.
]C                      Next code cell.
[C                      Previous code cell.
ic                      Inner-cell text object.
ac                      Around-cell text object, including its marker.

Counts are accepted by cell motions. Navigation adds the previous location to
the jumplist.

4. CELL OPERATIONS                                            *nvjup-cells*

<LocalLeader>jo         Insert code cell below.
<LocalLeader>jO         Insert code cell above.
<LocalLeader>jy         Duplicate cell and clear copied execution state.
<LocalLeader>jd         Delete current cell.
<LocalLeader>jk         Move current cell up.
<LocalLeader>jj         Move current cell down.
<LocalLeader>js         Split current cell at cursor.
<LocalLeader>jm         Merge current cell with the next one.
<LocalLeader>jt         Cycle code, Markdown, and raw cell types.
<LocalLeader>jz         Collapse or expand cell source.
<LocalLeader>jx         Collapse or expand cell output.
<LocalLeader>jc         Clear cell output.
<LocalLeader>jl         Open notebook outline.

All mappings are buffer-local and configurable.

==============================================================================
5. LANGUAGE TOOLING                                        *nvjup-language*

Each code language has one hidden shadow document, allowing language servers
to see definitions and references across code cells. Markdown and raw cells
are excluded. IPython magics are replaced by syntax-safe placeholders only in
the shadow document.

Tree-sitter parses each cell in its own language and projects highlight
captures into the visible composite buffer. Missing parsers degrade cleanly.

The default LSP mappings mirror ordinary code buffers:

gd                      Definition.
gD                      Declaration.
gi                      Implementation.
<Leader>D               Type definition.
gr                      References.
K                       Hover.
<Leader>ls              Signature help.
<C-Space>               Completion in Insert mode.
<Leader>ra              Rename across code cells.
<Leader>ca              Safe code action.
<LocalLeader>ls         Document symbols.

Diagnostics, semantic tokens, locations, and safe WorkspaceEdits are mapped
back from shadow buffers. Edits crossing a cell boundary, synthetic separator,
or IPython placeholder are rejected.

6. COMMANDS                                                 *nvjup-commands*

:NvJupWrite             Save the notebook.
:NvJupRefresh           Synchronize model and redraw extmarks.
:NvJupCellNext          Move to next cell.
:NvJupCellPrevious      Move to previous cell.
:NvJupCellInsertAbove   Insert a cell; optional type argument.
:NvJupCellInsertBelow   Insert a cell; optional type argument.
:NvJupCellDuplicate     Duplicate current cell with cleared execution state.
:NvJupCellDelete        Delete current cell.
:NvJupCellMoveUp        Move current cell up.
:NvJupCellMoveDown      Move current cell down.
:NvJupCellSplit         Split current cell at cursor.
:NvJupCellMergeBelow    Merge current cell with the next cell.
:NvJupCellType          Set or cycle cell type.
:NvJupCellToggleSource  Collapse or expand current cell source.
:NvJupCellToggleOutput  Collapse or expand current cell output.
:NvJupCellClearOutput   Clear output and execution count.
:NvJupOutline           Open cell outline through vim.ui.select().
:NvJupLspDefinition     Go to definition.
:NvJupLspDeclaration    Go to declaration.
:NvJupLspImplementation Go to implementation.
:NvJupLspTypeDefinition Go to type definition.
:NvJupLspReferences     List references.
:NvJupLspHover          Show hover documentation.
:NvJupLspSignature      Show signature help.
:NvJupLspCompletion     Request completion.
:NvJupLspRename         Rename; optional new-name argument.
:NvJupLspCodeAction     Select and apply a safe code action.
:NvJupLspSymbols        List document symbols.
:NvJupLspSemanticTokens Refresh projected semantic tokens.
:NvJupLspStatus         Show shadow documents and attached clients.

==============================================================================
7. CURRENT LIMITATIONS                                  *nvjup-limitations*

Stage 2 does not execute cells. Saved outputs are rendered as terminal text and
capability placeholders. Kitty image placement, interactive Plotly/Bokeh, and
Jupyter kernels are scheduled for later stages. Completion currently uses
Neovim's built-in completion UI and does not apply completion-item additional
text edits.
